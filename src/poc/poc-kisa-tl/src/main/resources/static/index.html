접수 · 심사 · 보완 · 반려

PoC 범위 제외. 메뉴만 제공합니다. 사업자·서비스·인증서는 관리자가 사업자·서비스 화면에서 직접 등록합니다. 신청 처리 상태는 서비스 인정 상태로 저장하지 않습니다.

사업자 등록

내부 providerId는 자동 부여되며 이름을 바꿔도 유지됩니다.

신뢰서비스 등록

같은 Subject·공개키의 인증서만 한 서비스로 등록됩니다. 키가 다르면 별도 서비스입니다.

서비스 정보 수정

유형은 바꿀 수 없습니다. 상태는 ‘상태 변경’으로 바꿉니다.

정상 기준 발행 전에는 정정, 발행 후에는 변경 효력 시각(현재 시작 이후)입니다.

상태 변경

사유는 관리 메타데이터로만 보관하며 TL XML에 싣지 않습니다.

인증서 추가 (같은 키 갱신)

Subject·공개키가 기존 인증서와 같아야 합니다. 새 키는 ‘서비스 등록’으로 새 서비스를 만듭니다.
