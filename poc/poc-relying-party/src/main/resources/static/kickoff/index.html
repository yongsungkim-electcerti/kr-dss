POINT 2 · KR-TL 사전 검증·경험

4검증 API 연계 및 이력 보존
운영 절차·정책·예외 기준을 실증 결과로 도출하여 KISA 신뢰검증체계 운영의 판단자료로 제공한다.
POINT 3 · 차세대 인증 기술 선점
전자서명 인프라를 차세대 인증 기술로 확장하는 발판을 본 연구에서 함께 마련한다.

장기검증(LTV)·원격전자서명·AI 인증까지 아우르는 차세대 전자서명 기술 로드맵의 출발점을 확보한다.
선행 구현 확인 WebAuthn 기반 인증서 발급 데모
