패스키 미등록 접속 환경 확인 중

인증서 발급 / 조회

서버는 PC(sol-pc)에서 실행되고, 전자서명 패스키는 현재 접속 중인 삼성 태블릿에 생성됩니다. 사업자 CA가 패스키 공개키에 사용자 인증서를 발급합니다.

현재 기기에 저장

현재 기기의 기본 패스키 제공자에 전자서명 개인키를 생성합니다.

기존 원격서명(HSM) 인증서 조회

전자서명 생성

원문과 서명 규격을 선택하고 서명을 요청합니다. 요청 시 SAD 생성과 함께 WebAuthn 사용자 인증을 수행합니다.
문서 H(doc)＋ 서명시각＋ 서명자 인증서 H(cert) →SignedAttrs →Challenge = BASE64URL(Hash(DER)) →WebAuthn 어서션 = 전자서명
WebAuthn 미지원 환경 — PIN + TOTP 대체 경로

서명 검증

KR-AdES 서명객체를 검증합니다. 원문을 함께 제공하면 문서 무결성(다이제스트 일치)까지 확인합니다.

인증서 관리 — Registration Binding · Multi-RA · 생명주기 · HSM

단일 WebAuthn 등록으로 복수 RA 인증서를 발급(동일 SPKI/SKI·RA별 정책 OID)하고, 인증서별 생명주기(정지·재개·폐지·갱신)와 HSM 발급(CSR+Attestation)을 시연합니다.
WebAuthn 등록 1회→ CA (단일 rpId)→ RA-A 인증서/ RA-B 인증서 ·동일 SPKI · 동일 SKI · RA별 Policy OID

HSM 원격서명 인증서 발급 (CSR + HSM Attestation)

HSM 을 모사하여 서버가 키쌍·CSR 을 생성하고, Attestation 검증 결과·키 비추출성에 따라 등급 정책을 부여합니다.
