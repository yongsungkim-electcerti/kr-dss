# assets — 캡처·이미지 폴더

슬라이드에 들어갈 이미지를 이 폴더에 아래 이름 그대로 저장한다.
파일을 두면 슬라이드의 점선 자리표시 박스가 자동으로 이미지로 바뀐다. 파일이 없으면 안내 문구가 그대로 보인다.

| 파일명 | 사용 페이지 | 내용 | 권장 크기 |
|---|---|---|---|
| `p02_pdf_viewer.png` | P02 지금 PDF 서명을 열면 | 브라우저 내장 PDF 뷰어에서 전자서명된 PDF를 연 화면. 서명 표시가 없거나 빈약하게 나오는 상태가 그대로 보이는 것이 좋다 | 1200×900 이상 |
| `p03_cms_chain.png` | P03 PKI 전자서명 인증 체계 | CMS(SignedData) 구조와 서명자 → 중간 CA → 루트 체인 검증 도식. 기존 자료의 도식을 그대로 쓰거나 별도 제작한다 | 1200×900 이상 |
| `p05_ca_manual.png` | P05 신뢰목록 사용, 지금은 수동이다 | 인증센터 웹사이트에서 인증서·서비스 정보를 사람이 조회하는 화면 | 1200×900 이상 |

- 형식은 PNG를 권장한다. 슬라이드에서 `object-fit: contain`으로 표시하므로 비율이 달라도 잘리지 않는다.
- 배경이 투명한 PNG는 흰색 위에 얹힌다.
- 파일명을 바꾸려면 `v03/build_v03.py`의 `shot(...)` 호출 경로를 함께 수정한다.
