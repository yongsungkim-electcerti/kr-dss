# 디지털 신뢰체계 국제동향 원문 보관

두 원문 폴더를 2026-09-27에 이 폴더로 통합했다.

- [국제동향 분석 문서](../수집문헌_요약_및_국제동향.md)
- [원문 파일 색인·출처·해시](원문_색인.md)
- `00_기본문헌`: 기본 문헌 7개의 PDF 8개. UN의 기존 보관본과 재다운로드본을 함께 보존한다.
- `01_EU_TLv6`부터 `12_PQC_EDPS_개인정보보호`까지: 원문 56개와 ARF 이동 안내 HTML 1개.
- `수집기록`: 이전 요약, 다운로드 목록, 재다운로드 결과와 PDF 검사 기록. 이전 날짜의 기록은 당시 상태를 나타낸다.

전체 원문·웹 응답 파일은 65개(PDF 32개·HTML 31개·TXT 2개)다. 중복 형식·이동 안내·UN 보관본이 포함되어 있어 독립 문헌 수와 다르다. 파일 이동 전후의 SHA-256을 대조해 원문 바이트가 유지됐음을 확인했다.

기본 문헌 중 공개 원문 6개는 웹에서 다운로드했고 EIF 초안은 사용자 제공 원본을 복사했다. EU 집행결정과 호주 정책 발표 원문은 다운로드하지 못했다. OECD·EDPS의 안내 페이지는 미확보이나 해당 PDF는 보관했다. ARF 이동 안내 HTML은 본문으로 사용하지 않는다.

수집기록의 CSV `file` 열은 이 원문 폴더를 기준으로 해석한다. 기존 F 드라이브 파일은 변경하지 않았다.
