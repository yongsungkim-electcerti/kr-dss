What is the Assessment Toolbox?
This Toolbox is a
collection of complementary tools and resources
provided by the European Commission to support the practical implementation of interoperability assessments under the
Interoperable Europe Act
. It supports the implementation of the
Interoperability Assessments Guidelines
, which define how assessments should be carried out.
The tools are designed to work
together as one interoperable ecosystem
, while remaining modular so you can use only what you need.
It includes:
Tools
you can use directly to prepare, conduct and report an assessment
Supporting resources
to help you structure and document the assessment
Technical building blocks
that keep information consistent and reusable

Guidelines for interoperability assessments
✅ Available
👤 Public administrations at national, regional, local levels/ European Union Institutions, Bodies and Agencies
Developed and adopted by the Interoperable Europe Board, the Guidelines for Interoperability Assessments
provide clarity
and
set a
starting point
for the assessment report journey.
Online tool for interoperability assessments
✅ Available
👤 Public administrations at national, regional, local levels
The online tool for interoperability assessments is a web-based tool enabling public administrations to
prepare and submit interoperability assessment reports
. The tool provides a structured workflow aligned with the requirements of the Interoperable Europe Act, guiding users through the information, analysis and documentation needed to complete an assessment.
🌐 Assess cross-border interoperability
EIF checker for Policymakers
⏳Upcoming
👤 Public administrations at national, regional, local levels/ European Union Institutions, Bodies and Agencies
The European Interoperability Framework (EIF) Checker is a
structured questionnaire
aimed at
detecting their effects on cross-border interoperability
. It is based on the EIF and structured across the interoperability layers and principles. The Checker is structured around the interoperability enablers around features a Discovery and Assessment Questionnaire. The current version is being developed in an Excel file.
AI for Digital-ready Policymaking (AI4DRPM)
⏳Upcoming
👤European Union Institutions, Bodies and Agencies
Digital Statements are now required for every legislative proposal within the European Commission.
AI4DRPM
is a
system
that analyses draft legislation to identify and classify digital relevance and generates a draft Digital Statement. Policy officers remain fully in control and are responsible for reviewing and finalising the output.

Interoperability Assessments Vocabulary
✅ Available
👤 Public administrations at national, regional, local levels/ European Union Institutions, Bodies and Agencies
The Interoperability Assessment Vocabulary
is a reusable and extensible
data model
that
defines the classes, properties and relationships used to describe interoperability assessments
. It provides the structured foundation needed to ensure that assessment data is represented consistently across tools and can be exchanged, validated and reused reliably.
Online tool for interoperability assessments
✅ Available
👤 Public administrations at national, regional, local levels
The online tool for interoperability assessments helps you
prepare, submit and publish interoperability assessment reports
.
Assessments repository
✅ Available
👤 Public administrations at national, regional, local levels/ European Union Institutions, Bodies and Agencies
The Assessments Repository is an
online repository
that enables public administrations to publish interoperability assessment reports conducted under the Interoperable Europe Act. The repository serves as the
central location
where
all assessments, whether completed through the Online Assessment Tool or uploaded independently
via the Interoperable Europe Portal,
are stored and made accessible
. It supports transparency, facilitates reuse and provides a common reference point for monitoring.
Application-Programme Interface (API)
✅ Available
👤Public administrations at national, regional, local levels/ European Union Institutions, Bodies and Agencies
The
API
and its documentation define the
technical interface
that will enable public administrations to
retrieve and submit interoperability assessment reports automatically
. Instead of conducting reports via the online assessment form, public administrations will be able to connect their internal systems via the API to upload reports to the report repository.
