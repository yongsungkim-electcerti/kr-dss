# EIF 문서 윤문 검토 기록

검토일: 2026-09-26

적용 스킬: im-not-ai의 humanize-korean. quick-rules의 규칙에 따라 기존 Google Docs를 직접 수정했다.

- [최종 번역본](https://docs.google.com/document/d/1kvg-tYOKaQu0DulsgnSajlizwXVLPgJ7V0HdARjiass/edit): 148개 구간, 변경률 0.4%.
- [국내 상호연동 시사점 보고서](https://docs.google.com/document/d/1ZsJIwZqOEA_EDoo9GwC5is8zVuSMB8_ZgPPcX3Oyq78/edit): 20개 구간, 변경률 0.7%.

수정 대상으로 확정한 구간의 탐지 결과는 연결어미 뒤 불필요한 쉼표(C-11) 140→0, 번역본의 반복 연결 표현(D-1) 13→2, 긴 수식 구조(A-18) 7→0, 이중 조사(A-19) 2→0이다. 기술 용어와 원문 구조상 보존한 표현은 수정 대상에서 제외했다. 구간 수와 변경 글자 비율은 서로 다른 지표다.

원문과 수정본을 대조하여 제목, 표 내용, 하이퍼링크의 문구·주소, 날짜 칩, 그림 요소, 기존 목차의 보존을 확인했다. 수치·영문 토큰·인용문 및 의무·가능성 표현을 대조했다. 최종 PDF의 전체 축소 미리보기로 배치를 확인했다. 보고서는 참고자료의 문단 간격을 줄였다.

스킬 체크리스트 자체검증 6/6, 등급 B. 변경률이 A 기준(10~25%)에 미달하며 불필요한 수정을 늘리지 않았다. 정밀 검증은 Claude Code의 정밀 모드(3콜)를 권장한다. 이 평가는 문체 윤문에 한정하며 원문 번역에 대한 독립 전문 감수를 의미하지 않는다.

기술 기록: trusted-read 브리지가 Windows 절대 경로를 인식하지 못해 공식 커넥터의 전체 문서 읽기로 원문을 확보했다. 기존 문서를 재생성하지 않고 수정 위치와 revisionId를 지정한 native API 요청을 사용했으며, 수정 후 다시 읽어 결과를 확인했다. 로컬 파일에는 본문과 편집 내역만 저장하고 원시 커넥터 응답은 저장하지 않았다.

PDF 사본: 두 문서의 윤문된 본문은 반영되어 있다. 다만 보고서 참고자료의 마지막 문단 간격 조정 이후 PDF를 재수출하는 과정에서 커넥터 전송 오류가 발생했다. 보고서 PDF는 해당 간격 조정 직전 사본이며, 최종 서식은 Google Docs를 기준으로 한다. 간격 조정 후 문서를 다시 읽어 본문이 동일함을 확인했다.
