KR-TL이 제공하는 기능 5가지 기능 › 전체

KR-TL은 신뢰앵커 제공, 시점 기준 상태 판정, 서비스 유형 구분, 목록의 진위 보장, 배포·동기화 다섯 가지 기능을 제공한다. 검증 엔진이 KR-TL에 요청하는 모든 것은 이 다섯 안에 들어온다.

F1
신뢰앵커
제공
인증서 경로 구성의 종착점이 될 서비스 인증서를 목록으로 내려준다
없으면이용기관이 앵커를 직접 수집·하드코딩
F2
시점 기준
상태 판정
서명 시점에 그 서비스가 어떤 상태였는지를 소급해 판정한다
없으면과거 서명이 사업자 지위 변경만으로 무효화
F3
서비스
유형 구분
서명용·타임스탬프·검증 서비스를 구분해 용도 밖 사용을 걸러낸다
없으면타임스탬프용 인증서로 문서 서명해도 통과
F4
목록의
진위 보장
목록에 서명·발행시각·유효기간을 부여해 위조와 노후화를 막는다
없으면신뢰 판단의 근거 자체가 공격 대상
F5
배포
·동기화
정해진 주소에서 주기적으로 목록을 받아 최신 상태를 유지한다
없으면상태 변경이 검증 시점에 반영되지 않음
F1~F3은 검증 엔진이 소비하는 기능이고, F4~F5는 브라우저 쪽에 실제 기능이 생기는 영역이다.
열어 둘 질문 다섯 중 웨일에서 부담이 큰 것과 작은 것이 어떻게 갈리는지 궁금합니다. 특히 F5의 갱신 주체를 브라우저 본체로 볼지 별도 컴포넌트로 볼지는 웨일 구조를 아는 쪽에서 판단하는 편이 정확합니다.
