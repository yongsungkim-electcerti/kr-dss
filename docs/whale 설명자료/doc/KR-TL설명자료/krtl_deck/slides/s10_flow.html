④에서 하는 일
서명자 인증서의 발급자·서비스 식별정보를 적용 중인 KR-TL과 대조한다. 결과는 등록됨 / 미등록 / 서비스 철회 / 목록 만료 / 목록 접근 불가 / 목록 서명 오류로 구분한다.
④에서 하지 않는 일
문서 변조 판정, 서명값 유효성 판정, 폐지 여부 판정. 이 셋은 각각 ② ③ ⑤의 결과다.
열어 둘 질문 ④와 ⑤는 외부 참조가 필요하고 ①~③은 로컬에서 끝납니다. 로컬 결과를 먼저 표시하고 나머지를 나중에 채우는 방식이 웨일 렌더링 구조에서 자연스러운지 판단이 필요합니다.
