절차
  1. KISA가 인정사업자 정보를 모아 KR-TL을 발행하고 서명
  2. 웨일이 배포 주소에서 목록을 주기적으로 내려받음
  3. 목록 서명·발행시각·유효기간을 확인한 뒤 적용
  4. 문서를 열 때 목록을 조회해 자동 판정
  5. 사용자가 결과를 화면에서 바로 확인
