# KR-TL 관리 시스템 설계

> 대상: KISA가 운영하는 한국형 신뢰목록(KR-TL)의 관리·배포 체계
> 성격: **전체 시스템 설계, 목표는 PoC(개념 증명)**
> 범위: 1차 — 기본 KR-TL (Attestation·장치 신뢰목록 제외)
> 최종 갱신: 2026-10-04

## 무엇을 증명하는가

> 관리자가 TL을 바꾸면, 그 변화가 배포를 거쳐 이용자·브라우저의 검증 결과에 **시점까지 정확하게** 반영되고, 그 과정은 위조·누락 없이 추적된다.

## 구성

**인증사업자** ─ **신뢰체계 관리 시스템 (KISA · 신뢰앵커)** ─ **이용환경 (가입자 · 브라우저 · 이용자)**

## 확정된 구성 원칙

1. 관리 시스템은 폐쇄망, TL 서명은 관리 시스템 HSM에서만 한다.
2. 관리 ↔ 배포는 채널 하나(IF-06 패키지 반출)이며 방화벽으로 통제하고, 연결은 관리 쪽에서만 시작한다.
3. 외부에 노출되는 것은 배포 WEB뿐이다. 배포 WAS가 접속 기록을 저장하고 수신 현황을 보여 준다.
4. 인증사업자는 기존 VPN으로 관리 시스템에 연결한다.
5. 관리자 접근 채널과 외부 배포 채널은 분리한다.
