## 기본 설계와 데모의 관계

- **기본 설계(01·02)** 는 실제 운영 환경을 전제로 한다. 망 분리, HSM, VPN 등 실제 보안 구성을 그대로 기술한다.
- **데모 시스템(03)** 은 기본 설계를 가정해 PoC 모듈로 축소한 것이다. 축소한 부분은 항목별로 "기본 설계 ↔ 데모 대체"로 표시한다.

## 1차 범위

- 포함: 인정사업자(인증기관)·서비스·인증서 관리, KR-TL 생성·승인·서명·배포, 배포 이력, 배포 접속 통계, 관리자 접근 통제, 감사로그
- 제외: WebAuthn/HSM Attestation 검증, 장치 신뢰목록(특허-C), LOTL(목록의 목록) 계층
