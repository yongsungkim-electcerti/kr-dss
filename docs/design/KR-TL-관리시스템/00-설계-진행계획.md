## 3. 진행 방식

- **단계 = 작업 브랜치 1개 = PR 1개**를 기본으로 한다. 브랜치 이름: `feat/claude-krtl-d<번호>-<주제>` (예: `feat/claude-krtl-d3-data-model`).
- 각 단계 산출물은 이 폴더에 번호를 붙여 추가하거나 기존 문서를 보완한다.
- 구성요소·IF가 바뀌면 **구성도(01, draw.io)를 먼저** 고치고 나머지 문서를 맞춘다.
- 운영 수치·정책 값은 정하지 않고 "향후 결정"으로 남긴다.
- 각 단계 완료 시 이 문서의 상태 표를 갱신한다.
