# 요구사항별 검증 명세 — 실행 전 초안

모든 TC는 이번 요구사항에 대한 신규 검증 계획이며 **미실행**이다. 기존 개발 문서의 시험 결과는 현재 요구사항·커밋·환경과 대조하지 않았으므로 EVD로 승계하지 않았다. 보류 범위는 확정 후 실행하며 아래 표가 해당 개발을 승인하지 않는다. 단계별 세부 절차·자동화 코드는 5단계에서 보완한다.
