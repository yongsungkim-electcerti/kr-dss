# 기능목록 — v0.4 구현 반영

기존 24개 기능에 FUN-025~027을 추가하여 총 27개다. [v0.4 변경 정의](tl-explorer-definition.md)에 따라 FUN-009~011은 후보 검사·변경 확인·별도 적용으로 구체화한다. 기존 정의와 충돌하는 부분은 v0.4가 우선한다.
