# 원본 요구사항과 Dev-Pulse 식별자 연결

v0.4: FR-103/POC-03, FR-107/POC-07, FR-110/POC-10의 구체적인 추가 인수 조건은 [TL 구조 설명·변경 비교 정의](tl-explorer-definition.md)를 따른다. 요구 ID와 총 10개 범위는 유지한다.

POC ID는 사용자 검토 ID 그대로 유지한다. FR-101~110은 이 폴더 안의 검사기 연결용 별칭이며 신규 기능 요구 10개를 추가한 것이 아니다. 출처·설명은 원본 엑셀에서 읽었다.
