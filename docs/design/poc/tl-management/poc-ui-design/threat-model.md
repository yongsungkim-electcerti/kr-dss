# 최소 위협·통제 설계

PoC 기능이 다루는 입력·신뢰정보·키·결과에 한정한다. 통제는 설계 상태이며 구현·검증됨이 아니다.

| ID | 위협 | 분류 | 대상 자산 | 신뢰 경계 | 진입점 | 위험도 | 대응 통제 | 처리 | 상태 |
|---|---|---|---|---|---|---|---|---|---|
| TH-001 | 악성 XML·경로·큰 입력으로 파일 노출 또는 처리 자원 고갈 | 정보 유출 | AST-001, AST-003 | TB-001 | 파일 입력 | 높음 | CTRL-001 | 완화 | 대응 설계 |
| TH-002 | 변조·비신뢰 TL 또는 이름만 같은 키를 신뢰정보로 채택 | 위장 | AST-002 | TB-002 | TL 채택·신뢰점 매칭 | 높음 | CTRL-002 | 완화 | 대응 설계 |
| TH-003 | 키 본문이 화면·로그·내보내기로 노출 | 정보 유출 | AST-001 | TB-003 | 서명 설정·오류 응답 | 높음 | CTRL-003 | 완화 | 대응 설계 |
| TH-004 | 예상값·다른 조건·실행중 교체로 잘못된 증거와 비교 결론 생성 | 무단 변경 | AST-004 | TB-004 | 결과 저장·비교·재현 | 보통 | CTRL-004 | 완화 | 대응 설계 |

| ID | 통제 | 관련 요구사항 | 대응 위협 | 적용 위치 | 강제 주체 | 실패 시 동작 | 검증 시험 | 잔여 위험 | 상태 |
|---|---|---|---|---|---|---|---|---|---|
| CTRL-001 | 파일 파싱·경로·자원 제한 | FR-101, FR-105 | TH-001 | 파일 입력 처리 | 서버 코드, OS 권한 | 외부 엔티티·루트 이탈·초과 입력 거부; 제한 미확정 시 구현 보류 | TC-025 | OS 권한 탈취는 범위 밖; 제한 수치 OQ-002 | 설계 |
| CTRL-002 | 신뢰앵커 분리·서명 검증·공개키 매칭·최신성 검사 | FR-103, FR-104, FR-108, FR-109 | TH-002 | 후보 채택·체인 검증 | 서버 검증 코드 | 후보 거부, 기존본도 무효면 NO_VALID_TL | TC-010, TC-012, TC-016 | 시험 정책의 한계·외부 법적 효력은 미판정 | 설계 |
| CTRL-003 | 키 별칭 사용·비밀값 제거 | FR-101, FR-110 | TH-003 | 서명 처리·오류·내보내기 | 서버 코드, OS 권한 | 키 본문·암호 반환 및 export 차단 | TC-005, TC-023 | 로컬 파일키 자체의 운영 보호 수준은 미입증 | 설계 |
| CTRL-004 | 입력 고정·불변 실행 기록·비교 조건 확인 | FR-105, FR-107, FR-110 | TH-004 | 실행·보존·비교 | 서버 코드 | 조건 불일치는 비교 제한; 입력 변화는 새 run | TC-015, TC-018, TC-020, TC-024 | 실행 환경 시계의 외부 신뢰성은 미입증 | 설계 |

권한 상승: 입력 경로를 통한 키 영역 접근과 XML 외부 엔티티를 CTRL-001로 제한. 서비스 거부: 파일 크기·파싱·실행 제한은 OQ-002에서 수치를 확정. 정보 유출: CTRL-001·003 적용. 별도 운영 권한·감사 기능을 신설하지 않는다.
