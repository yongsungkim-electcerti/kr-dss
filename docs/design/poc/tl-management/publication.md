# TL 생성·발행·제공

1. 초안을 읽고 정상 권장 순번·시각을 표시한다. 사용자가 의미 오류 값을 입력할 수 있다.
2. 후보 스냅숏을 고정하고 XML을 편성한다.
3. 사전 검사 결과를 안내하고 키 파일로 서명한다. 의미 오류와 키 읽기·서명 실패를 구별한다.
4. 생성된 암호 서명을 확인하고 XML·메타데이터를 issuanceId별로 저장한다. 저장 실패는 생성 성공이 아니다.
5. 관리자가 제공본을 선택한다. 최대 순번을 자동 선택하지 않는다.
6. WAS가 저장된 바이트를 IF-07로 제공한다. GET에서 재서명·재직렬화하지 않는다.

순번·시각의 의미 오류는 관리 화면에서 발행·제공 가능해야 한다. 생성 성공은 외부 검증 모듈의 수용을 뜻하지 않는다. 보관본은 덮어쓰지 않으며 재제공은 같은 바이트를 사용한다.

[IF-07](interfaces/28-IF07-TL-조회-API.md): `/tl/kr-tl.xml`, `/tl/kr-tl.sha2`, XML 해시 기반 ETag/304. 별도 WEB 서버는 구성하지 않는다.
