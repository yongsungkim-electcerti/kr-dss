# TL 관리 PoC 범위

상태: 사용자 결정 반영. 기준일: 2026-10-08.

| 구분 | 범위 |
|---|---|
| 구현 | 사업자·신뢰서비스·인증서 관리, 상태 이력, 초안 영속 저장, TL XML 생성·키 파일 서명, 불변 발행본 보관, 현재 제공본 선택, IF-07 공개 조회 |
| 오류 발행 | 순번·발행 시각·NextUpdate·상태 시작 시각 조정. 정상 키로 서명된 의미 오류 TL도 보관·제공 |
| 메뉴만 제공 | 접수·심사·보완·반려. 실제 업무 처리로 표시하지 않음 |
| 제외 | 인증·권한·감사, HSM 연계, 별도 WEB 서버, 이용기관 PDF 검증·CA/OCSP·원격서명 기능 개발 |
| 유보 | 상세 PoC 시나리오·표본·시험 시계·비교 화면·초기화 도구의 완료 기준 |

WAS는 선택한 발행본을 그대로 제공한다. 내용의 수용 여부는 외부 검증 모듈 책임이다. 관리 화면은 생성 성공·현재 제공본·검증 결과를 구분한다.

기존 다른 PoC 소스는 보존하지만 이번 관리시스템 기능 목록에는 합산하지 않는다. 전체 시스템의 IF-01~08 명칭은 유지하며, 해당 번호가 모든 기능의 구현을 뜻하지 않는다.
