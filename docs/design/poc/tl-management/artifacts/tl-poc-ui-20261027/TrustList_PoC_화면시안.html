예외·대조 기록의 표시 방식

TL 거부 기록은 후보 번호·거부 이유·유지한 적용본을 보여줍니다. 미등재 체인은 신뢰 근거 부족, 실제 인증서 서명 관계 오류는 체인 오류로 구분합니다. 참고 예상값과 실제 출력은 별도 열에 둡니다.
