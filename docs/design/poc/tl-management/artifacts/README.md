개발 상태와 시험은 [개발 문서](../../../../development/poc/tl-management/README.md), 실행법은 [사용 안내](../../../../guides/poc/tl-management/tl-verification-poc.md)에서 연결한다. 요구·기능을 수정할 때 해당 엑셀과 연결 문서를 같은 변경으로 관리하고, 이전 산출물의 기준 버전을 명시한다.

실행 로그·시험 원본·키·다운로드 표준과 과거 상세설계 백업은 main의 Git 비관리 경로에 유지한다. 이 폴더에는 개발 문서 산출물만 둔다.
