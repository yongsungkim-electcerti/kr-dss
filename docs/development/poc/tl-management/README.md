# TL 관리 PoC 개발

기준일: 2026-10-09. 작업 공간 정리와 개정 개념 설계 검토를 완료했다. 상세 구현 설계의 보완점은 남아 있으며, 제품 코드 수정은 다음 세션에서 진행한다.

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 공통 모델 확장 | 현재·이력, 형식 버전·순번, 서비스 식별자 구분 |
| 2 | 관리 API·초안 저장 | 사업자·서비스 입력, 저장, 재기동 후 복원 |
| 3 | XML 생성·키 파일 서명 | 실제 서명본 생성, 실패 시 성공 표시 금지 |
| 4 | 발행본 보관·선택 | issuanceId별 불변 보관, 동일 순번 다른 내용 보존 |
| 5 | IF-07 제공 | 선택한 XML 바이트·해시 일치, ETag/304 |
| 6 | 관리 화면 연결 | 입력·생성·제공·검증 결과 구별 |
| 7 | 기술 검증·인계 | 정상·오류 발행, 재제공, 저장·서명 실패 검증 |
