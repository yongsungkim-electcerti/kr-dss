# TL 관리 PoC 개발

기준일: 2026-10-09. 공통 모델·XML 변환, 관리 화면·초안 저장, PoC 키 체계, XML 서명·발행본 보관, 제공본 선택·IF-07을 구현했다. PDF 뷰어용 TL 수신 검증 샘플을 추가했다. 다음은 오류 TL 시험 조작 보완과 기술 검증·인계다. 전체 XSD 적합성·외부 소비자 프로파일 지원·파일 원자 교체와 복구는 후속 검증 대상이다.

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 공통 모델 확장 — 1차 구현 완료 | 현재·이력, 형식 버전·순번, 서비스 식별자 구분. 전체 XSD 필드는 후속 보완 |
| 2 | 관리 화면·초안 저장 — 구현 완료 | 화면에서 사업자·서비스·인증서 직접 입력, 저장, 재기동 후 복원 ([33](reviews/33-관리화면-초안저장-구현결과.md)) |
| 3 | XML 생성·키 파일 서명 — 구현 완료 | 실제 서명본 생성, 실패 시 성공 표시 금지 ([34](reviews/34-XML서명-발행본보관-구현결과.md)) |
| 4 | 발행본 보관·선택 — 구현 완료 | issuanceId별 불변 보관, 동일 순번 다른 내용 보존 |
| 5 | IF-07 제공 — 구현 완료 | 선택한 XML 바이트·해시 일치, ETag/304 ([35](reviews/35-제공본선택-IF07-구현결과.md)) |
| 6 | 관리 화면 연결 — 입력·생성·제공 완료 | 입력·생성·제공·검증 결과 구별(외부 검증 결과는 미확인 표시) |
| 7 | 기술 검증·인계 | 정상·오류 발행, 재제공, 저장·서명 실패 검증 |
