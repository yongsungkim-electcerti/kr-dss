# 전체 검토 결과

2026-10-07. Google Docs의 최신 본문과 삽입 그림을 기준으로 검토했다.

## 반영

- 7장: 이용환경의 TL 검증, 신뢰점·상태, OCSP·TSA 신뢰, 수용 정책과 결과를 구분했다.
- 8장: 관리 기능 목록을 재구성하고 편집 가능한 대시보드 도식을 작성·삽입했다.
- 9장: 표 4개와 그림 3개를 보존하여 이용 시나리오 별지로 분리했다.
- 전체: 제목과 항목을 간결하게 정리하고, 중복 설명·이전 IF 설명을 줄였다. 그림 번호와 별첨 목록·링크를 맞췄다.
- 윤문: 기술 조건과 판정 의미를 유지하면서 설명을 짧게 나누고, 이름을 먼저 쓰며 코드만으로 설명하는 표현을 줄였다.
- 사용자 삭제 부분은 복원하지 않았다. PDF 변환은 하지 않았다.

## 다음 검토

- 1장부터 최신 Google Docs를 다시 읽으며 세부 내용을 다듬는다. 로컬 보관본으로 원격 문서를 덮어쓰지 않는다.
- 그림 4의 신뢰정보(IF-01)와 TL 서명(IF-05) 화살표가 배포 시스템으로 연결되어 있다. 본문은 그림 1 기준으로 관리 영역의 접수·발행·서명을 설명한다. 사람이 수정한 그림은 유지했으며 연결 표현은 다음 세부 검토 대상이다.
- 그림 10의 신뢰앵커 전달 표현은 자동 신뢰로 오해될 수 있다. 본문에서는 사전에 신뢰한 KISA TL RootCA를 기준으로 검증하도록 명시했다.
- 시나리오 그림 내부의 기존 ‘그림 3 참조’는 본문 2.2 인증 체인 구성(현재 그림 4)을 가리키므로 후속 도식 편집에서 수정한다.
- Google Docs 자동 목차의 항목·쪽수 새로고침과 페이지 배치는 수동 확인이 필요하다.
