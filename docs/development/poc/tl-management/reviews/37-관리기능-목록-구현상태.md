## 요약

- 사업자 등록 → 서비스·인증서 입력 → 초안 저장 → 서명·발행 → 제공본 선택(배포) → IF-07 조회 흐름은 구현되어 있다.
- 처음 실행하면 초안 r1(사업자 0건)이어서 화면이 비어 보인다. `scripts/poc/tl-management/seed-demo-data.ps1`로 PoC 키 세트의 TL 등재 노드(사업자 4, 서비스 10)를 넣을 수 있다. `-Publish`를 주면 정상 발행과 제공본 선택까지 수행한다.
- 범위상 필수인데 빠진 기능은 오류 TL의 상태 시작 시각 조정이다.
- 편의 기능 미구현: revision 비교·되돌리기, 발행과 제공 일괄 처리, XSD 검사.

## 시연 데이터 (2026-10-12 입력)

`seed-demo-data.ps1` 실행 결과. 인정 시작 시각은 실행 시각이다. UN(미등재 대조군)과 KISA 공동인증 RootCA(K-00)는 넣지 않았다.

| 사업자 | 분야 | 서비스 (인증서) |
|---|---|---|
| 가상공동인증A | JOINT | CA 레벨 CA (JA-01), OCSP (JA-02), TSA (JA-03) |
| 가상공동인증B | JOINT | CA 레벨 CA (JB-01), OCSP (JB-02), TSA (JB-03) |
| 가상간편인증A | SIMPLE | CA 레벨 ROOT (SA-00) |
| 가상간편인증B | SIMPLE | CA 레벨 CA (SB-01), OCSP (SB-02), TSA (SB-03) |

재실행하면 같은 이름의 사업자·서비스를 건너뛴다(14건 건너뜀 확인). 기존 항목을 수정·삭제하지 않는다.
