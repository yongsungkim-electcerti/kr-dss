# 35. 제공본 선택·IF-07 구현 결과

작성일: 2026-10-09. 브랜치 `feat/claude-tl-admin`. 개발 단계 4의 제공본 선택, 단계 5(IF-07 제공), 단계 6(관리 화면 연결)의 제공 부분을 구현했다.

## 구현 범위

| 구분 | 내용 | 소스 |
|---|---|---|
| 제공 포인터 | state.json에 `publicationRevision`·`servedIssuanceId` 추가(기존 v2 파일은 0·미선택으로 읽음). 확정 목록 밖을 가리키면 기동 시 상태 불가 | `RegistryStore.State`, `selectServed` |
| 제공본 선택 | 관리자가 고른 확정 발행본만, 기대 publicationRevision 일치 시 원자 교체. 선택 전 파일 해시 확인. 의미 오류·과거 순번·시험 발행본도 선택 가능. 정상 기준·권장 순번 불변 | `IssuanceService.select` |
| IF-07-01 | `GET/HEAD /tl/kr-tl.xml`: 저장 바이트 그대로, `application/vnd.etsi.tsl+xml`, `ETag: "sha256-<hex>"`, `Cache-Control: no-cache, no-transform`, If-None-Match(약한 비교·`*`) → 304 | `web/TlPublicController` |
| IF-07-02 | `GET/HEAD /tl/kr-tl.sha2`: 같은 바이트의 SHA-256 raw 32바이트, `application/octet-stream` | 〃 |
| 오류 | 404 `TL_NOT_PUBLISHED`(미선택), 503 `TL_UNAVAILABLE`(상태 불가·파일 손상, 다른 발행본으로 대체하지 않음), 406 `NOT_ACCEPTABLE`, 405 `METHOD_NOT_ALLOWED`(Allow: GET, HEAD, OPTIONS), 500 `INTERNAL_ERROR`. 모두 `text/plain; charset=utf-8`, `no-store` | 〃 |
| 요청 일관성 | 한 요청에서 상태 스냅숏 하나로 제공 ID를 고정하고 그 바이트의 해시를 확정값과 대조 | `IssuanceService.served` |
| CORS | 공개 경로에만 `*`, 자격 증명 없음, `ETag` 노출, `If-None-Match` 허용, GET·HEAD | `@CrossOrigin` |
| 화면 | TL 발행: 현재 제공본 카드(발행 ID·목적·순번·선택 revision·공개 주소), 발행본 행의 ‘제공본으로’ / ‘제공 중’. 운영 현황의 현재 제공본 | `static/index.html` |

## 검증

- `gradlew.bat build` 통과. poc-kisa-tl 33건(IF-07·선택 6건 신규) 실패 0.
  - 미선택 404, 선택 후 저장 바이트 일치·매체 유형·ETag·Cache-Control, 일치 ETag 304·불일치 200, sha2 32바이트·해시 일치, HEAD
  - 정상 기준 뒤 하위 순번 TRIAL 선택 시 그 바이트를 그대로 제공하고 정상 기준 불변
  - 오래된 선택 revision 거부, 미확정 ID 거부
  - 제공 파일 변조 시 XML·sha2 모두 503
  - 406·405·CORS 노출 헤더
- 기존 임시 저장소(제공 필드 없는 state.json)로 기동해 확인: 선택 전 404, 순번 100 TRIAL 선택 후 200·ETag·304·sha2 일치, 같은 revision 재선택 409, CORS preflight(Allow-Origin `*`, Allow-Headers If-None-Match, Expose ETag), HEAD, POST 405, Accept json 406. 화면에서 순번 2 정상 발행본으로 제공본 전환.

## 한계

- 503의 Retry-After는 설정하지 않았다(설계상 서버 설정값, 수치 미정).
- XML GET과 sha2 GET 사이에 선택이 바뀌면 둘이 다를 수 있다(설계대로 소비자 재조회).
- 이용기관·뷰어 쪽 IF-07 소비와 TL 검증 연동은 하지 않았다. 외부 검증 결과는 미확인이다.
- 상태 시작 시각만 바꾼 오류 TL 생성(초안 외 시험 override)은 아직 없다.
