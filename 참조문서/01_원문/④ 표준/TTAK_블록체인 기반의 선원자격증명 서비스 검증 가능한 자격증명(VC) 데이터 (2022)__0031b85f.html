한글 표준명 블록체인 기반의 선원자격증명 서비스 검증 가능한 자격증명(VC) 데이터
영문 표준명 Verifiable Credential Data of Blockchain-based Seafarers Qualification Service
한글 내용요약 본 표준은 블록체인 기반 모바일 선원자격증명 서비스 필요성, 요구 사항, 모바일 선원자격증명 참여자(발급자, 소유자, 검증자) 별 DID에 저장되는 DID 문서 규격, 모바일 선원자격증명 발급, 제출, 검증 시나리오에 따른 VC, VP 및 DID 상호작용 규격 및 참여자 간 상호인증 규격, 모바일 선원자격증명의 전송 모드에 따른 송수신 메시지를 정의한다. 또한, 분산 식별자로 연결된 모든 노드에서 소유자인 선원의 모바일 선원자격증명 인증정보를 안전하게 인증할 방법을 설명하며, 모바일 선원자격증명 인증정보를 이용한 블록체인 기반의 모바일 선원자격증명에 대한 범용 인증 방법을 기술한다.
영문 내용요약 This standard defines the need and requirements for a Blockchain-based mobile seafarer’s qualification certificate, defines the DID Document specification stored in the DID for each mobile seafarer’s qualification certificate participant (issuer, owner, validator), and issuance, submission, and verification of a mobile seafarer’s qualification certificate. Defines VC∙VP standards for each scenario and mutual authentication standards between participants, and defines transmission/reception messages for each transmission mode of mobile seafarer’s qualification certificate. It explains how to securely authenticate the user's mobile seafarer’s qualification certificate authentication information on all nodes connected by DID. And a Blockchain-based mobile seafarer’s qualification certificate universal authentication method using mobile seafarer’s qualification certificate authentication information is described.
