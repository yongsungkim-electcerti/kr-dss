Release history

The current section provides an overview of the changes in each GITB TDL release.

Release numbers follow global numbering covering all Test Bed components, meaning that certain releases may have not actually introduced changes to the GITB TDL. The current page lists only the releases that introduced changes, whereas those not included are global maintenance releases that made no changes to the GITB TDL.

The latest GITB TDL release is 1.30.0.

Release 1.30.0 - 21/09/2026

Description of changes

Relevant sections

New result element for the receive step to adapt the step’s report before completion and, for the HttpMessagingV2 and SoapMessagingV2 handlers, dynamically generate the returned response.

Adapting the step’s result and generating responses, HttpMessagingV2, SoapMessagingV2

Unmatched incoming calls to the HttpMessagingV2 and SoapMessagingV2 handlers are now automatically parked and retried, reducing the need for a custom messaging service to handle simple race conditions.

receive

New handlerApiType attribute to select the REST or SOAP API style used to call an external test service handler.

Selecting the API style for external service handlers

New built-in PdfValidator handler to validate PDF documents, including conformance to PDF/A and PDF/UA profiles.

PdfValidator

New TextProcessor built-in handler with operations for encoding and decoding text.

TextProcessor

New replace operation for the RegExpProcessor handler to perform text replacements based on regular expressions.

RegExpProcessor - replace

Support for CTA (Complex Type Alternative) XPath checking in XML Schema 1.1 for the XmlValidator and XsdValidator handlers.

XmlValidator, XsdValidator

The TemplateProcessor now processes any parameter values as long as they can be represented as primitive values.

TemplateProcessor

New scope attribute for the exit step to stop the execution of a step sequence, loop, flow or scriptlet without terminating the test session.

Stopping execution without ending the test session

New hiddenContainer attribute for the flow step to hide its boundary in the test execution diagram.

flow

New ACTOR alias to more easily refer to the SUT actor’s own configuration properties in test cases.

Actor configuration parameters

New dependsOn, dependsOnValue and included attributes for instruct and request elements of interact steps, to conditionally display or include them based on other provided inputs.

Conditionally including and depending on interaction elements

Support for rich text (HTML) content in instruct elements via a mimeType of text/html.

Displaying data using instruct elements

The desc attribute of instruct elements is now optional, to simplify displaying instructions without titles.

Displaying data using instruct elements

The interact step’s request elements now allow multiple values for a single UPLOAD input via the multiple attribute.

Providing multiple values for a single input

The test suite and test case lastModified timestamp values are now displayed toi administrators.

Metadata (test case), Metadata (test suite)
