## 정리 기준

1. 원문은 파일 내용을 바꾸지 않고 복사했다. SHA-256, 출처 URL, 기존 경로는 통합목록 JSON에 남겼다.
2. 동일 내용은 한 파일로 연결했다. 해시가 다른 판·형식은 임의로 합치지 않았다.
3. PDF 전문, 웹 본문, 서지·초록, 안내 화면을 구분했다. 논문·ISO 표준의 전문 미확보는 확보현황에 표시했다.
4. 추가 목록에 없는 자료는 주된 역할로 분류했다. 일본 신뢰 포털은 법·제도에, 연결된 실증·자문 보고서는 해외사례에 배치했다.
5. 원문 언어는 유지했다. 영어 자료 외 한국어·일본어 자료도 포함된다. 요약은 원문 번역을 대체하지 않는다.
6. Google Sheets는 분류 기준과 목록을 읽는 데 사용했으며 수정하지 않았다. 기존 조사 목록의 수천 개 후보 링크를 실제 확보 문헌 수에 포함하지 않았다.
7. 기존 번역본과 국내시사점·통합 분석은 기존목록과기록 및 기존산출물 보존 폴더로 옮겼다. 본 폴더의 원문 수에 번역·분석 산출물을 포함하지 않았다.

## 파일 검증

복사한 모든 파일의 SHA-256이 원래 파일과 일치한다. 통합 안내·목록·요약의 로컬 링크를 확인했다. PDF 58개는 모두 열기와 텍스트 추출을 수행했다. 일부 PDF에서 글꼴·문자 위치·내부 참조 등의 읽기 경고가 발생하여 [검사 기록](04_수집기록/PDF_읽기경고.json)에 남겼다. 원본 바이트를 보존했으며 텍스트 추출본의 표·그림·문자 배치가 원본과 같다고 보장하지 않는다.


## 기존 폴더 정리

사용자 요청에 따라 기존 세 폴더를 하위 폴더·파일까지 삭제 완료했다. 원문 외 번역 PDF·분석 산출물·그림·작업자료는 [기존산출물 보존](05_기존산출물_보존)에 추가 보관했다. 기존 보고서의 Markdown은 [기존목록과기록](04_수집기록/기존목록과기록)에 있다. [삭제 전 보존 검증 기록](04_수집기록/기존폴더_삭제전_보존검증.json)에서 각 기존 파일의 새 위치를 확인할 수 있다.
