EIF 2017과 Next EIF Blueprint Draft 0.2를 비교해 프레임워크 자체의 발전 방향과 일반적 시사점을 분석했다. 특정 산업·국가의 도입 방안은 범위에서 제외했다. 원문 근거 페이지와 초안의 한계를 함께 기록했다.
