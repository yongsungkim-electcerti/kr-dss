# 03 부속3 — 국가별 신뢰 프레임워크 원문 심층조사 기록

조사일: 2026-09-29. [부속1](03_부속1_해외_국가별_신뢰프레임워크_조사.md)의 1차 웹 조사에서 가치가 높다고 본 국가를 대상으로, 각국의 신뢰 프레임워크 문서 **원문**을 열어 실체를 확인한 기록이다. 권역별 조사 6건의 결과를 모았다.

## 이 기록의 지위

- **정의 확정 전의 기록**이다. 아래 "1차 판정"은 조사 시점의 잠정 기준으로 매겼다. 잠정 기준은 "영국·뉴질랜드·PCTF·호주처럼 역할·규칙·인정·감독을 하나의 체계로 묶었는가"였다. [0번 문서 1장](../../기술문서/00_신뢰프레임워크_분석_EIF중심.md)의 정의와 판정 기준(E1~E8, 신뢰 프레임워크/부분적/구성요소)이 확정되면 다시 판정한다.
- 조문 번호·금액 일부는 요약 도구를 거쳐 읽었다. 인용 전에 원문과 대조해야 한다.
- 조사 후반에 웹 검색 한도가 소진됐다. 그래서 일부 원문은 `미확인`으로 남았다.
- 부속1과 내용이 다르면 **이 기록이 우선**한다. 부속1에서 바로잡을 사항은 6장에 정리했다.

## 2. 유럽

### 스웨덴
- **문서**: Tillitsramverk för Svensk e-legitimation(Digg, 사건번호 2018-158, 9쪽). 구성은 1 배경 / 2 조직·거버넌스 / 3 물리·관리·인적 보안 / 4 기술 보안 / 5 신청·신원확인·등록 / 6 발급·폐지 / 7 전자신원 검증 / 8 신원 어설션 발급.
- **구속력**: 라이선스 계약의 부속서 2다(부속서 1 품질마크, 3 변경절차, 4 보고절차). 공공 조달 인가제(Lag 2023:704, Förordning 2023:709)에 참여하려면 이 승인을 먼저 받아야 한다. 기술 계층은 Sweden Connect Technical Framework(SAML·OIDC, 연합 메타데이터)가 맡는다.
- **요건 예**: K2.1 법인·보험, K2.3 1년 운영 재원, K2.4·K2.5 ISMS(수준 4는 SS-ISO/IEC 27001:2014), K2.8 기록 10년, K2.9 3년 주기 내부감사, K4.3 HSM·다중인원 통제, K5.10~K5.12 대면/원격 확인(수준 4는 원격 불가), K6.1 2요소, K6.5 유효기간 최대 5년.
- **절차**: 착수 회의 → 신청 → 위험기반 심사(현장 방문) → 승인 → 계약(3·4수준). 수준 2는 매년 갱신한다. 연례 내부감사 보고서와 사고·통계·변경 보고를 제출한다. 수수료는 없다.
- **원문**: https://docs.swedenconnect.se/technical-framework/mirror/digg/Tillitsramverk-for-Svensk-e-legitimation-2018-158.pdf (확인됨), 승인 목록 https://www.digg.se/digitala-tjanster/e-legitimering/om-e-legitimering/godkanda-e-legitimationer-och-intygsfunktioner (확인됨). 라이선스 계약은 미확인.

### 핀란드
- **문서 계층**: 법 617/2009(개정 811/2026, 2026-10-01 시행) → 정부령 169/2016(미확인) → Traficom 규정 M72B/2022(구속력) → 권고 216/2022 S(행동규범), 212/2023 S·213/2023 S(SAML·OIDC 프로파일), 211/2023 O·214/2023 O(평가·신고 지침).
- **역할(법 §2)**: 인증수단 제공자, 인증 중계 제공자, 신뢰당사자, 신뢰 네트워크, 평가기관, 내부감사기관, EUDI 지갑.
- **요건 예**: M72B §4 ISO 27001 수준 보안관리, §6.2 거래 식별·신뢰당사자 표시, §7 암호 요건, §8.1 적격 서명·인장 등으로 상호 인증, §11 사고신고, §12 필수 전달 속성, §16 재정능력·종료계획. 법 §12c는 수단 제공자가 받는 대가를 거래당 최대 3센트로 제한한다.
- **절차**: 신고와 독립 평가 보고서(유효 최대 2년). 요건 미달이면 제공 금지. §47 수수료는 신·구 문구를 대조해야 한다.
- **감독**: §45 경고·시정, §45a 임시조치, §46 현장검사, §12d 구성원 간 손해배상. **§12e**: 중계자는 EUDI 지갑 인증을 중계할 수 있다.
- **원문**: M72B https://www.kyberturvallisuuskeskus.fi/sites/default/files/media/file/M72B_2022_M%C3%84%C3%84R%C3%84YS_72B_tunnistus-_ja_luottamuspalvelut_julkaistu.pdf (확인됨), 법 https://www.finlex.fi/fi/lainsaadanto/2009/617 (확인됨).

### 덴마크
- **문서**: NSIS v2.1(Digst, 2024-06-28 발행, 2024-06-30 발효, 이행 2025-01-01). 구성은 서론 / 생애주기·신뢰사슬 / 인증수단 요건 / 조직·공통 요건 / 법인 연계 / **신원 브로커 요건** / 거버넌스(소유·유지, 종료, 책임·보험, 비용, 사고공유).
- **역할**: 전자식별제도, 신원 브로커, 신원서비스, 서비스제공자. 서비스제공자에게는 규범 요건이 없다. 신고는 역할별로 한다.
- **요건 예**: §4.1.3 High는 ISO 27001 인증, §6 브로커 FAL·HSM(FIPS 140-2 L3), §7.3 책임보험 1,000만 DKK, §7.5 심각한 사고 보고.
- **절차**: Lav는 자기선언과 경영진 확인서. Substantial·High는 독립 감사인 또는 CAB 감사의견서와 통제양식을 내고 매년 갱신한다. Digst는 형식만 심사한다. 미준수 시 포지티브리스트에서 삭제된다.
- **별도 체계**: MitID 브로커 인증(IN Groupe, 11개 브로커 승인).
- **원문**: https://digst.dk/media/s0spdxxi/national-standard-for-identiteters-sikringsniveauer-nsis.pdf (확인됨), https://digst.dk/tilsyn/nsis/ (확인됨). MitID·NemLog-in법 원문은 미확인.

### 노르웨이
- **문서**: FOR-2019-11-21-1578(최신 개정 FOR-2025-10-14-2043). 근거는 전자신뢰서비스법 2018-06-15-44. 구성은 목적·정의 / 자기선언(§3~§16) / 보안수준(§17~§21) / 시행.
- **내용**: 역할은 eID 제도 제공자와 Nkom 둘뿐이다. 요건은 2015/1502를 그대로 재사용하고, 주민번호 연결을 요구한다. 자기선언 신고(§7)를 하면 Nkom이 확인하며(§9), 제3자 감사를 명령할 수 있다(§10). 이행강제금(§14), 목록 삭제(§13), 부과금(§15)이 있다.
- **EUDI**: Digdir 샌드박스의 "Tillitsrammeverk"는 신뢰목록 구조(119 612 XML / 119 602 JWT)를 설명하는 기술 페이지다. 거버넌스 프레임워크가 아니다.
- **원문**: https://lovdata.no/dokument/SF/forskrift/2019-11-21-1578 (확인됨).

### 네덜란드
- **문서**: Afsprakenstelsel Elektronische Toegangsdiensten(eTD). EU 통보 목록의 영문명은 "Trust Framework for Electronic Identification"이다. 현행은 **AS1.24e**(2026-06-25 제정, 2026-08-04 공표)다. 소유자는 BZK, 관리조직은 Logius다.
- **구속력**: 협약 본문, 참여자 계약, 이용약관의 사법상 계약 체계다. Wdo §4.3(제11~15조) 법정 인정조항은 **미시행**이다.
- **구성**: 용어집 / 법적 틀·가입요건·감독·보증수준·약관 / 운영핸드북·SLA / SAML / 공통규범(Normenkader, 2015/1502 구조) / 템플릿.
