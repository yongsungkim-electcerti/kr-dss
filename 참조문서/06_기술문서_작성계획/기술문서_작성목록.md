# 기술문서 작성 목록

작성일: 2026-09-29. 첫 기술문서인 **EIF 중심 신뢰 프레임워크 분석**을 출발점으로 삼아 이어서 작성할 기술문서 20편을 정리했다. [통합 목록](../02_목록/통합목록.md)의 원문과 기존 산출물([EIF 차세대 상호운용성 분석](../04_수집기록/기존목록과기록/EIF_차세대_상호운용성/04_통합문서/EIF_차세대_상호운용성_분석_국제동향포함.md), [국내시사점](../04_수집기록/기존목록과기록/디지털신뢰_국제동향_20260926/국내시사점.md))을 근거로 했다.

문서는 EIF의 상호운용성 계층(법률 → 조직·거버넌스 → 의미 → 기술)을 따라 배열했다. 이어서 과업 산출물(KR-AdES · KR-TL · KR-DSS)과 연계되는 문서를 두고, 사례와 종합 문서로 마무리한다.

## 작성 순서

1. **1~3번(법·제도)** — 기준 문서(0번)의 법률 계층을 바로 이어받는다.
2. **15·16·11·12번** — KR-TL·KR-DSS 구현과 PoC에 직접 입력되므로 앞당겨 작성한다.
3. 나머지 조직·의미·기술 계층 문서(4~10, 13, 14, 17, 18)와 사례 분석(19)을 작성한다.
4. **20번(종합)** — 앞선 19편의 결론을 모아 마지막에 작성한다.

## 선행 확인 사항

- 학술연구 가운데 DBpia·KCI 논문 6편은 서지·초록만 확보했다([추가 참조목록 확보 현황](../02_목록/추가참조목록_확보현황.md) 참조). 13·14번 작성 전에 전문을 확보해야 한다.
- ISO 5009는 코드 목록 페이지만 확보했으며 표준 전문은 없다. 7번 작성 시 이 범위를 명시한다.
